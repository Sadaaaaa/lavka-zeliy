# Лавка зелий

Игра-головоломка для iPad и телефона. Серая хмарь забрала цвета у волшебных зверей, а игрок смешивает зелья в котле и возвращает их.

Без сборки и зависимостей: HTML, CSS, SVG и обычный JS. Прогресс хранится только на устройстве, аккаунтов и сбора данных нет.

## Запуск

```bash
npm start
```

Игра откроется на http://localhost:8770. С iPad или телефона в той же сети Wi-Fi: `http://<адрес-Mac>:8770`. Адрес Mac покажет `ipconfig getifaddr en0`.

Работа без интернета и установка как приложения требуют HTTPS, то есть публикации на хостинге. В локальной сети игра открывается как обычная страница.

## Проверка

```bash
npm test
```

## Что где лежит

- `js/levels.js`: звери, реплики и рецепты. Новый уровень добавляется здесь.
- `js/engine.js`: смешивание цветов, сравнение, подсказки и звёзды.
- `js/animals.js`: рисунки зверей, котла и пузырьков.
- `js/app.js`: экраны и сохранение прогресса.
- `sw.js`: работа без интернета. Новые файлы нужно добавлять в его список.

Шрифт Neucha распространяется по лицензии SIL OFL (`fonts/LICENSE-Neucha.txt`).
